# TestAutomation

Автоматизация тестирования фронтенда (Nuxt.js) и бэкенда (Go) для обеспечения качества кода и стабильности системы.

## Назначение

Скилл автоматизирует все виды тестирования в стеке Nuxt.js + Go:
* юнит‑тесты;
* интеграционные тесты;
* E2E‑тестирование;
* тестирование API;
* генерацию отчётов по покрытию кода.

## Функциональные возможности

### 1. Модульное тестирование
* запуск `go test` для бэкенда;
* запуск Vitest для компонентов Nuxt.js;
* измерение покрытия кода (Go и Nuxt);
* генерация отчётов в HTML и LCOV.

### 2. Интеграционное тестирование
* проверка взаимодействия фронтенда и бэкенда через API;
* тестирование бизнес‑логики с временными БД;
* валидация данных между слоями приложения.

### 3. E2E‑тестирование
* автоматизация пользовательских сценариев (Playwright/Cypress);
* визуальное регрессионное тестирование;
* проверка SSR‑функциональности Nuxt.js.

### 4. Тестирование API
* валидация OpenAPI/Swagger‑спецификаций;
* нагрузочное тестирование (k6);
* мониторинг времени ответа эндпоинтов.

### 5. Отчётность
* сводные отчёты по всем видам тестов;
* визуализация метрик качества кода;
* уведомления в Slack/Telegram;
* хранение истории результатов.

## Команды скилла

| Команда | Описание | Пример использования |
|-------|-------|-------|
| `test:unit` | Запуск юнит‑тестов | `skill test:unit` |
| `test:integration` | Запуск интеграционных тестов | `skill test:integration` |
| `test:e2e` | Запуск E2E‑тестов (Playwright/Cypress) | `skill test:e2e --browser=chromium` |
| `test:api` | Тестирование и валидация API | `skill test:api --load=100` |
| `coverage:report` | Генерация отчёта по покрытию | `skill coverage:report --format=html` |
| `data:seed` | Создание тестовых данных | `skill data:seed --env=staging` |
| `report:generate` | Полный отчёт по тестированию | `skill report:generate --output=pdf` |
