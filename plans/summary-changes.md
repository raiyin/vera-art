# Сводка изменений в архитектурном плане

## Добавленные возможности

### 1. Расширенная схема базы данных

**Новая таблица: `product_categories`**
- `name_ru`, `name_en` - названия категорий
- `slug` - уникальный идентификатор для URL
- `description_ru`, `description_en` - описание категории
- `sort_order` - порядок сортировки
- `is_active` - активна ли категория

**Расширенная таблица: `products`**
- `category_id` - ссылка на категорию
- `instructor_id` - ссылка на пользователя-преподавателя
- `short_description_ru`, `short_description_en` - краткое описание
- `tags` - JSON массив тегов для поиска и фильтрации
- `prerequisites_ru`, `prerequisites_en` - требования к студентам
- `learning_outcomes_ru`, `learning_outcomes_en` - чему научится студент
- `certificate_available` - выдается ли сертификат
- `max_students` - ограничение по количеству студентов (для мастер-классов)
- `start_date` - дата начала (для мастер-классов с фиксированной датой)
- `language` - язык контента (ru/en/both)
- `is_featured` - выделенный продукт на главной
- `view_count` - количество просмотров

**Расширенная таблица: `lessons`**
- `resources` - JSON массив дополнительных ресурсов (PDF, ссылки)
- `homework_ru`, `homework_en` - задание для самостоятельной работы
- `estimated_study_time` - рекомендуемое время изучения в минутах
- `is_required` - обязательный ли урок
- Добавлен тип контента `assignment`

### 2. Новые API эндпоинты

**Категории продуктов (раздел 2.3)**
- `GET /categories` - список всех категорий (публичный)
- `GET /categories/:slug` - продукты в категории (публичный)
- `GET /admin/categories` - управление категориями (admin)
- `POST /admin/categories` - создание категории (admin)
- `PUT /admin/categories/:id` - обновление категории (admin)
- `DELETE /admin/categories/:id` - удаление категории (admin)

### 3. Обновленный план реализации

**Фаза 1 (добавлено):**
- Создание таблицы `product_categories`
- API для управления категориями
- Компонент CategoryFilter для фильтрации по категориям
- CategoryStore для работы с категориями на фронтенде

## Преимущества добавленных изменений

1. **Лучшая организация контента**: Категории позволяют структурировать курсы и мастер-классы
2. **Улучшенный поиск и фильтрация**: Теги и категории упрощают навигацию
3. **Гибкость для разных типов продуктов**: Поддержка мастер-классов с фиксированными датами и ограничением студентов
4. **Международная поддержка**: Поля на русском и английском языках
5. **Расширенная аналитика**: Поле `view_count` для отслеживания популярности
6. **Система сертификации**: Флаг `certificate_available` для курсов с сертификатами

## Влияние на сроки реализации

**Минимальное увеличение сроков:**
- Бэкенд: +1-2 дня (таблица категорий + API)
- Фронтенд: +1-2 дня (компоненты фильтрации)
- База данных: +0.5 дня (дополнительные миграции)

**Общее увеличение: 2-4 дня** к первоначальной оценке в 45 человеко-дней.

## Рекомендации по внедрению

1. **Начать с категорий**: Создать базовые категории (акварель, масло, графика и т.д.)
2. **Постепенное заполнение**: Добавлять расширенные поля по мере необходимости
3. **Обратная совместимость**: Старые продукты могут не иметь всех новых полей
4. **Миграция данных**: Скрипт для заполнения категорий существующих продуктов
