# Система согласия на использование файлов cookie и обработку персональных данных

## Соответствие законодательству

### 1. GDPR (Общий регламент по защите данных ЕС)
- **Статья 7**: Условия согласия
  - Согласие должно быть добровольным, конкретным, информированным и недвусмысленным
  - Реализация: Пользователь явно выбирает категории cookie через интерактивный баннер
  - Возможность отозвать согласие в любое время через интерфейс пользователя

- **Статья 12**: Прозрачная информация
  - Ясный и понятный язык о целях обработки данных
  - Ссылки на Политику конфиденциальности и Условия использования
  - Многоязычная поддержка (русский/английский)

- **Статья 13**: Информация, предоставляемая при сборе данных
  - Идентификация контролера данных
  - Цели обработки
  - Правовая основа обработки
  - Период хранения данных
  - Права субъектов данных

- **Статья 30**: Ведение записей об обработке
  - Аудит всех изменений согласий в таблице `consent_audit_log`
  - Хранение IP-адреса, User-Agent, времени и версии политики

### 2. Федеральный закон № 152-ФЗ (Россия)
- **Статья 9**: Согласие субъекта персональных данных
  - Согласие должно быть конкретным, информированным и сознательным
  - Возможность отзыва согласия
  - Документальное подтверждение согласия

- **Статья 18.1**: Обязанности оператора
  - Обеспечение безопасности персональных данных
  - Уведомление Роскомнадзора (при необходимости)
  - Назначение ответственного за организацию обработки ПДн

- **Статья 22**: Уведомление об обработке ПДн
  - Оператор обязан уведомить уполномоченный орган

### 3. ePrivacy Directive (Директива о конфиденциальности электронных коммуникаций)
- Требует согласия перед размещением необязательных файлов cookie
- Исключение для технически необходимых cookie
- Четкое информирование о целях использования cookie

## Архитектура реализации

### Фронтенд компоненты
1. **CookieConsent.vue** - интерактивный баннер согласия
   - Отображается при первом посещении сайта
   - Позволяет выбрать категории cookie
   - Сохраняет предпочтения в cookies и localStorage
   - Интегрирован в корневой макет приложения (app.vue)

2. **CookieConsentStore.ts** - управление состоянием согласия
   - Хранение и извлечение согласия из cookies
   - Синхронизация с бэкендом для аутентифицированных пользователей
   - Управление аналитическими и маркетинговыми скриптами

### Бэкенд компоненты
1. **Миграция базы данных** (`003_cookie_consent_tracking.sql`)
   - Таблица `user_consents` - основные согласия пользователей
   - Таблица `cookie_consent_details` - детальные настройки по категориям
   - Таблица `consent_audit_log` - аудит всех изменений
   - Обновление таблицы `users` для быстрого доступа

2. **Модели данных** (`server/models/consent.go`)
   - Типизированные структуры для Go
   - Константы для типов согласий и категорий cookie

3. **API эндпоинты** (`server/consent.go`)
   - `POST /consent` - сохранение согласия
   - `GET /consent/status` - получение текущего статуса
   - `POST /consent/withdraw` - отзыв согласия
   - `GET /consent/policy-version` - версия политики
   - `GET /admin/consent/audit` - журнал аудита (админ)

### Категории файлов cookie

1. **Необходимые (Necessary)**
   - Обязательные для работы сайта
   - Не могут быть отключены
   - Включают: аутентификацию, безопасность, управление сессиями

2. **Аналитические (Analytics)**
   - Сбор анонимной статистики использования
   - Помогают улучшать пользовательский опыт
   - Требуют явного согласия

3. **Маркетинговые (Marketing)**
   - Отслеживание для персонализированной рекламы
   - Интеграция с социальными сетями
   - Требуют явного согласия

4. **Настройки (Preferences)**
   - Сохранение пользовательских предпочтений
   - Язык, тема, региональные настройки

## Процесс работы

### Для неаутентифицированных пользователей
1. При первом посещении отображается баннер согласия
2. Пользователь выбирает категории cookie
3. Предпочтения сохраняются в cookie `cookie_consent` (365 дней)
4. Дублируются в localStorage для надежности
5. Аналитические/маркетинговые скрипты загружаются только при согласии

### Для аутентифицированных пользователей
1. При входе в систему проверяется наличие согласия в cookies
2. Если согласие есть в cookies, оно синхронизируется с базой данных
3. Все последующие изменения сохраняются и в cookies, и в БД
4. При отзыве согласия обновляются обе системы хранения

### При смене аутентификации
- Анонимный → Аутентифицированный: cookies → БД
- Аутентифицированный → Выход: БД → cookies (сохраняются настройки)

## Права пользователей

В соответствии с GDPR и 152-ФЗ пользователи имеют право:

1. **Право на доступ** - просмотр своих данных согласия
2. **Право на исправление** - изменение предпочтений cookie
3. **Право на удаление** - отзыв согласия и удаление данных
4. **Право на ограничение обработки** - отказ от определенных категорий
5. **Право на переносимость данных** - экспорт данных согласия
6. **Право на возражение** - отказ от маркетинговой обработки

## Аудит и подотчетность

1. **Полное журналирование** всех действий с согласием
2. **Хранение метаданных**: IP, User-Agent, временные метки
3. **Версионирование политик** для отслеживания изменений
4. **Административный интерфейс** для просмотра журналов

## Развертывание

1. Применить миграцию базы данных:
   ```bash
   cd server
   ./scripts/apply_migrations.sh
   ```

2. Перезапустить сервер:
   ```bash
   go run main.go
   ```

3. Собрать и запустить клиент:
   ```bash
   cd client
   npm run build
   npm run start
   ```

4. Проверить функциональность:
   - Открыть сайт в режиме инкогнито
   - Убедиться в появлении баннера согласия
   - Протестировать различные варианты согласия
   - Проверить синхронизацию при аутентификации
