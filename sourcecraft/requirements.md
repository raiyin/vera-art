## Технические ограничения (Constraints)

| ID | Ограничение | Описание |
|----|-------------|----------|
| CON-01 | SQLite single-connection | Максимум 1 соединение к БД. Не подходит для высоконагруженных систем. |
| CON-02 | Локальное файловое хранилище | Изображения хранятся на локальной ФС. Требуется синхронизация при масштабировании. |
| CON-03 | In-memory rate limiter | Сбрасывается при перезапуске сервера. Не работает в multi-instance среде. |
| CON-04 | Отсутствие тестов | Нет unit/integration/e2e тестов. Риск регрессий при изменениях. |
| CON-05 | Отсутствие OpenAPI/Swagger | Нет автоматической документации API и генерации клиента. |
| CON-06 | Два API-клиента на фронтенде | Axios и fetch с разной логикой обработки auth. Усложняет поддержку. |
| CON-07 | Инлайн SQL-миграции | Миграции в main.go без версионирования. Сложно откатывать. |
| CON-08 | Отсутствие Docker | Нет контейнеризации для деплоя и разработки. |
| CON-09 | Отсутствие CI/CD | Нет автоматической сборки, тестирования и деплоя. |

## Рекомендации по улучшению

### Критические (High Priority)

1. **Добавить тесты** — unit-тесты для сервисов и handler'ов, интеграционные тесты для репозиториев.
2. **Добавить OpenAPI/Swagger** — генерация спецификации из кода (например, swaggo/swag).
3. **Унифицировать API-клиент** — использовать единый подход (Axios или fetch) на всём фронтенде.

### Средние (Medium Priority)

4. **Версионирование миграций** — использовать golang-migrate или аналог вместо инлайн SQL.
5. **Docker-контейнеризация** — Dockerfile + docker-compose для сервера и клиента.
6. **CI/CD pipeline** — GitHub Actions или аналог для автоматической сборки и деплоя.
7. **Добавить восстановление пароля** — flow с email-ссылкой.
8. **CSRF-защита** — добавить CSRF-токены для форм.

### Низкие (Low Priority)

9. **S3-совместимое хранилище** — замена локального файлового хранилища на MinIO/S3.
10. **Redis для кэширования** — кэширование API-ответов и rate limiting.
11. **WebSocket для чата** — замена polling на WebSocket для real-time сообщений.
12. **SEO-оптимизация** — sitemap, robots.txt, Open Graph.
13. **A11Y** — ARIA-атрибуты, поддержка screen reader.
14. **Мониторинг** — метрики (Prometheus), алертинг, логирование в централизованную систему.
